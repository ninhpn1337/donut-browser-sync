Linux: 

```
Thư mục dữ liệu chính (Chứa Profiles):

Bash
~/.local/share/DonutBrowser/
(Cụ thể, các profiles bạn tạo sẽ nằm trong ~/.local/share/DonutBrowser/profiles, tương đương với đường dẫn ~/Library/Application Support/... trên macOS).

Thư mục cấu hình (Tùy chọn):

Bash
~/.config/DonutBrowser/
```
